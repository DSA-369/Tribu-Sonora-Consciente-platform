# 🎵 Tribu Sonora Consciente — Web Platform www.tribusonoraconsciente.com

Plataforma web integral diseñada para la gestión, difusión y agendamiento de experiencias de sonoterapia, talleres vivenciales y venta de instrumentos acústicos de resonancia.

---

## 🚀 Características Principales

* **Agendamiento Automatizado:** Sistema de reserva y gestión de sesiones individuales y grupales de terapia sonora.
* **Catálogo & Tienda Online:** Exposición e inventario de instrumentos (cuencos de cuarzo, handpans, didgeridoos) y servicios.
* **Integración WhatsApp:** Canalización directa de reservas y confirmaciones de pago hacia atención personalizada.
* **Administración de Eventos:** Gestión de inscripciones para talleres y encuentros sonoros.
* **Arquitectura Full-Stack en Python:** Frontend y Backend unificados bajo el ecosistema de **Reflex**.

---

## 🛠️ Stack Tecnológico

| Capa | Tecnología |
| :--- | :--- |
| **Framework Full-Stack** | [Reflex](https://reflex.dev/) (Python + React / Tailwind CSS) |
| **Lenguaje Base** | Python 3.11+ |
| **Base de Datos & Auth** | Supabase / PostgreSQL |
| **ORM & Migraciones** | SQLModel / SQLAlchemy & Alembic |
| **Estilos & UI** | Radix UI + Tailwind CSS |
